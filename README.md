# Dynamic Rail ETAs

An AI-powered railway ETA prediction and train tracking system built for dynamic prediction of train arrival times using historical and live train data.

## Getting Started

### 1. Set the Start Date

Before running the data pipeline, open:

```text
python/blegh.py
```

Inside the file, locate:

```python
start_date = ...
```

Set `start_date` to a date **within the last 7 days**.

For example:

```python
start_date = date(2026, 8, 24)
```

> The date should be recent because the train data source only provides a limited historical window.

### 2. Run the Pipeline

After setting the start date, run the pipeline from the project root:

```bash
python python/runpipeline.py
```

The pipeline will fetch and process the required train data.

### 3. Run the Application

Once the data pipeline has finished, start the backend and frontend using their respective commands.

#### Backend

```bash
cd backend
npm install
npm start
```

#### Frontend

Open another terminal:

```bash
cd frontend
npm install
npm run dev
```

The frontend will then provide the web interface for the Dynamic Rail ETAs application.

## Data

Raw and generated train data is intentionally excluded from the repository. The required data can be regenerated by running the Python pipeline.

## Requirements

* Python 3.x
* Node.js
* npm

Install Python dependencies with:

```bash
pip install -r python/requirements.txt
```

Then follow the setup steps above.
